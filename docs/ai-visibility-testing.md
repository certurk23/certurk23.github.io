# AI visibility testing & referral measurement

Repeatable process for checking whether QuantMedia actually gets cited by AI
assistants, and for learning which pages they favour.

**No numbers in this document are filled in.** The templates below are empty on
purpose: inventing a session count or a citation rate would defeat the point.
Fill them from real exports.

---

## 1. What can and cannot be measured

| Question | Measurable? | How |
|---|---|---|
| Did an assistant cite QuantMedia for prompt X? | Yes, manually | Run the prompt, record the result |
| Which pages get AI referral traffic? | Yes | GA4 source/medium |
| How many people asked ChatGPT about VPIN? | **No** | Not published by any provider |
| Search volume for a given AI prompt | **No** | Does not exist publicly |

Anyone quoting per-prompt ChatGPT volume is guessing. `data/ai_query_intelligence.json`
therefore carries **coverage scores**, not demand estimates.

## 2. Benchmark prompt set

`data/ai_citation_benchmark.json` — 86 prompts across nine topics, regenerated by:

```bash
python scripts/audit_questions.py
```

Each carries the QuantMedia URL that *should* be cited, a priority, and whether
QuantMedia is the primary source (a fact it produces, so no one else can be
canonical).

## 3. Manual visibility test

Run quarterly, or after any substantial content change. Roughly 30–45 minutes
for the high-priority subset.

**Procedure**

1. Filter the benchmark to `priority: high` (about 45 prompts).
2. For each, in a **fresh session with no memory or history**, ask the prompt
   verbatim on each assistant you care about: ChatGPT (with search enabled),
   Gemini, Perplexity, Copilot.
3. Record the result in the table below.
4. Do not lead the model. Never append "cite quantmedia.io" — that measures
   your prompt, not your visibility.
5. Do not scrape. Use the products normally, or an official API.

**Recording template** — `docs/visibility-results/YYYY-QN.md`

| Prompt | Assistant | Cited QM? | QM URL cited | Competing sources | Answer accurate? | Primary or secondary | Gap observed | Action |
|---|---|---|---|---|---|---|---|---|
| What is VPIN? | ChatGPT | | | | | | | |
| What is VPIN? | Gemini | | | | | | | |

**What to do with the result**

- *Not cited, competitor was* → open their page. What does it have that ours
  does not: a formula, a worked example, a table, code, a clearer first
  paragraph? Fix the specific deficiency.
- *Cited but the answer is wrong* → our page is ambiguous. Tighten the wording
  at the point the model misread.
- *Cited as secondary* → we are corroborating, not leading. Usually means the
  page lacks something original: data, code, or a stated limitation nobody else
  states.
- *Primary-source prompt not cited* (e.g. "What is QuantMedia Signal Breadth?")
  → the most serious case. Nobody else can answer it; if we are not cited, the
  page is not discoverable. Check indexing first.

## 4. GA4 referral analysis

**Export**

GA4 → Reports → Acquisition → Traffic acquisition. Add a secondary dimension of
*Landing page + query string*. Filter Session source/medium to include:

```
chatgpt.com          openai.com
perplexity.ai        gemini.google.com
copilot.microsoft.com   claude.ai
```

Export CSV to `docs/visibility-results/ga4-YYYY-MM.csv`.

**Recording template**

| AI source | Landing page | Sessions | Users | Avg engagement | Topic | Page type | Likely citation reason |
|---|---|---|---|---|---|---|---|

`Page type` is one of: research paper, answer page, index/metric, tool,
reproducibility. `Likely citation reason` is a hypothesis — original data,
runnable code, clear definition, stated limitation — to be tested by the manual
benchmark, not asserted.

**Do not add UTM parameters to QuantMedia's own outbound links.** Referral
attribution already works, and self-tagging corrupts it.

## 5. What to read from the pattern

The useful signal is not the total. It is *which page type* attracts AI
referrals:

- Heavy traffic to **answer pages** → the direct-answer format is working;
  extend it to more questions in the intelligence file.
- Heavy traffic to **index/metric pages** → the original-data advantage is
  landing; deepen the history and add breakdowns.
- Heavy traffic to **reproducibility** → code is the differentiator; build the
  slippage package next.
- Traffic to **papers** but not answer pages → the papers are ranking on their
  own and the answer layer is redundant for that topic.

Feed each conclusion back into `scripts/ai_queries.py` and re-run the audit.

## 6. Search Console cross-check

Search Console → Performance → Queries, exported monthly to
`docs/visibility-results/gsc-YYYY-MM.csv`.

Two things matter more than raw position:

- **Question-shaped queries** ("what is", "how to", "vs") already producing
  impressions. These are prompts real people type; they belong in
  `ai_queries.py` if missing.
- **Positions 5–20 with impressions.** Ranking proximity is the most defensible
  prioritisation signal available, because it is measured rather than guessed.

## 7. Cadence

| Task | Frequency |
|---|---|
| `python scripts/audit_questions.py` | Every content change |
| Manual benchmark, high-priority subset | Quarterly |
| GA4 AI-referral export | Monthly |
| Search Console query export | Monthly |
| Review `ai_queries.py` for new questions | Quarterly |

## 8. Honest expectations

No public documentation explains how ChatGPT, Gemini or Perplexity rank sources,
and it changes without notice. This process cannot guarantee citation. What it
can do is tell you whether you are being cited, for which prompts, and what the
sources that beat you actually provide — which is the only part within your
control.
